autounattend.xml Generator

Configure Windows 10/11 in tabs (installation, account, privacy, performance, theme, apps…) with options inspired by Winhance. Everything runs in your browser; nothing is uploaded anywhere.

Independent project, not affiliated with or endorsed by Winhance (memstechtips). It does not produce Winhance's official file: it generates a standard autounattend.xml with embedded scripts that apply equivalent tweaks. Always review the XML before using it.

An answer file can erase disks and create accounts. Test in a virtual machine first. Use at your own risk.
