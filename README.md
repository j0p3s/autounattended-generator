# Autounattend Generator

An interactive, browser-based generator for Windows 10/11 `autounattend.xml` answer files, with options inspired by [Winhance](https://winhance.net/).

Pick your settings in tabs (installation, user account, privacy, performance, power, updates, theme, taskbar, apps…), preview the result, and download a ready-to-use `autounattend.xml`. Everything runs locally in your browser: no server, no tracking, no data leaves your machine.

> **Disclaimer:** this is an independent project. It is not affiliated with, endorsed by, or generated by Winhance (memstechtips). It does **not** produce Winhance's official answer file; it produces a standard `autounattend.xml` with embedded PowerShell scripts that apply equivalent tweaks.

## Features

- **Windows setup:** UI language, keyboard, time zone, edition and product key, architecture, Windows 11 hardware-check bypasses (TPM, Secure Boot, RAM, CPU, storage, disk), optional automatic disk partitioning, network disabled during setup, BypassNRO, .NET Framework 3.5, OOBE screen skipping.
- **User account:** create a local account automatically (name, password, administrator or standard, one-time auto-logon, password never expires), computer name (automatic, random generated by Windows, or custom with a random-name generator), registered owner and organization.
- **Privacy & security, Performance & gaming, Power, Updates, Notifications & sound:** registry and policy tweaks comparable to Winhance's *Optimize* categories.
- **Theme, Taskbar, Start menu, File Explorer:** tweaks comparable to Winhance's *Customize* categories.
- **Windows apps:** remove built-in Appx packages, optional Windows capabilities and features, and OneDrive.
- **Software (winget):** install packages on first logon from a list of winget IDs (import a `winget-apps.json` produced by `winget export`).
- **Languages:** English (default) and Portuguese, selectable from a menu. More languages can be added by extending the translation dictionary in `generator.html`.
- **Presets, import/export:** a *Recommended* button on every tab (plus *Reset tab*), global *Recommended* and *Gaming* presets; save and load your configuration as JSON.
- **XML preview and validation** with warnings for risky choices, plus a view of the embedded scripts.

## Usage

1. Open the generator page (`generator.html` on the GitHub Pages site of this repository, or open the file locally in any modern browser).
2. Go through the tabs and choose your options.
3. Open **Generate XML**, check the warnings, then click **Download autounattend.xml**.
4. Place `autounattend.xml` in the root of your Windows installation USB drive (next to `setup.exe`), or inject it into your ISO.
5. Boot from the USB drive and install Windows.

> The interface is in English by default. Use the language menu in the top bar to switch to Portuguese (pt-PT). The choice is remembered, and you can also link directly with `?lang=pt`.

## How it works

The generated XML configures three Windows Setup passes:

| Pass | What it does |
| --- | --- |
| `windowsPE` | Language, hardware-check bypasses (`LabConfig`), optional disk layout, edition/product key |
| `specialize` | Extracts embedded scripts, `BypassNRO`, disables network adapters, runs system-level tweaks (HKLM policies, Appx removal, default-user profile) |
| `oobeSystem` | Hides OOBE screens, creates the local account, re-enables the network and runs the first-logon script (per-user tweaks, winget installs) |

PowerShell scripts are stored inside a custom `<Extensions>` element of the XML. A short specialize-pass command reads `C:\Windows\Panther\unattend.xml` and writes them to `C:\ProgramData\WinTweaks\`. This avoids the command-length limit of `RunSynchronousCommand`. Logs are written to the same folder (`system.log`, `firstlogon.log`).

User-level tweaks (theme, taskbar, Explorer…) can be applied either to the default user profile (all new users) or only to the first user that signs in.

## Safety notes

- **Disk wipe:** the optional automatic partitioning erases disk 0 without asking. It is off by default and highlighted in the UI. Test in a virtual machine first.
- **Passwords:** a password set for the local account is stored in plain text inside the XML (and in `C:\Windows\Panther`). Never commit or share an XML that contains a real password.
- **Policies:** many tweaks use Group Policy registry keys. Windows may show "Some settings are managed by your organization". This is expected.
- **Updates:** disabling automatic updates stops security patches until you re-enable them.
- **Language:** the UI language you choose must exist in your Windows ISO.
- **Windows 11 24H2 and later:** `BypassNRO` may be ignored by newer builds. Creating the local account in the XML avoids the problem.
- Test status: the generator and the XML output were checked with automated tests (syntax, well-formedness, UI smoke test). Real-world installs on all Windows builds have not been exhaustively tested. Review the output and use at your own risk.

## Run locally

No build step is needed:

```
git clone https://github.com/<your-user>/autounattend-generator.git
cd autounattend-generator
# open generator.html in your browser
```

To preview the themed landing page locally (optional): `bundle install && bundle exec jekyll serve`.

## Publish with GitHub Pages

Repository **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`**. The site uses the [Midnight](https://github.com/pages-themes/midnight) theme (`_config.yml`). The landing page is `index.md`, available at `https://<your-user>.github.io/autounattend-generator/`, and the generator itself is at `https://<your-user>.github.io/autounattend-generator/generator.html`.
